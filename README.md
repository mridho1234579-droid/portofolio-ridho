# Portofolio Muhamad Ridho

Website portofolio statis (HTML, CSS, JavaScript) bertema biru. Tanpa framework, jadi bisa langsung dibuka atau diupload ke GitHub Pages.

## Cara memakai
1. Taruh fotomu di `assets/img/` dengan nama `foto-ridho.jpg` (rasio 4:5 / potret paling bagus, mis. 800x1000 px).
2. Buka `js/script.js`, isi bagian `KONTAK` (email, WhatsApp, GitHub, dll). Tombol hanya muncul kalau diisi.
3. Buka `index.html` di Visual Studio Code. Pakai ekstensi **Live Server** untuk pratinjau.

## Upload ke GitHub Pages
1. Buat repository baru di GitHub, mis. `portofolio`.
2. Upload semua isi folder ini (index.html harus berada di root repo).
3. Settings → Pages → Source: *Deploy from a branch* → Branch: `main` / `(root)` → Save.
4. Web kamu aktif di `https://USERNAME.github.io/portofolio/`.

## Struktur
```
index.html
css/style.css
js/script.js
assets/img/   (foto, screenshot proyek, logo)
```
